# SOYE KIDS · TeachAble Art Play 24주 수업 대시보드 고도화 개발 패키지

## 패키지 구성
- `curriculum-source-01-20.json`: 20개 PDF의 **모든 페이지 텍스트 원문**과 주차별 검토 요약, 충돌 플래그. 이미지 슬롯은 **실제 이미지가 아닌 빈 자리**임.
- `source_text/week-01.txt` ~ `week-20.txt`: PDF의 페이지 구분을 보존한 원문 추출. PDF의 시각적 배치는 실제 PDF로 확인.
- `weekly-review-matrix.csv`: 교안 비교/검수 표. 스프레드시트로 열 수 있음.
- `IMPLEMENTATION_BRIEF.md`: Claude Code가 그대로 읽을 수 있는 개발 요구사항.

## 중요한 주의
1. **21~24주차 PDF는 미첨부.** 해당 4개는 현행 GitHub 데이터를 읽고 기존 데이터로 유지하며 신규 내용이 있으면 별도 승인 후 변경.
2. **기존 공개 체험 사이트는 정적 안전 데모.** PDF의 `OB 관찰 기록 입력`, `FM 가정 연계`, `PR 물류`, `RP 성장 리포트`, `키즈보드` 라벨은 업무 기능을 이미 구현했다는 뜻이 아님.
3. PDF의 `+ 이미지`, `wN.*`는 에셋 슬롯 식별자이지 실제 이미지/음원/영상 파일이 아님.
4. 사용자의 요청은 **이전 버전의 디자인 유지**. 페이지 템플릿을 과도하게 바꾸지 말고 교사용 화면의 콘텐츠 가독성과 흐름만 개선.
5. 기존 35분 기본 수업은 편집된 체험용 구성. 일부 PDF의 CORE 45분 및 공식 교사용 원본의 50~70분을 원문과 분리해서 유지.
6. 새로운 첨부물 4, 7, 8, 14, 17~20주차 제목·주제 충돌이 큼. 원본을 자동으로 공식 주차명으로 덮어쓰면 안 됨.
7. 공개 사이트에 아동 사진/영상 업로드, 개인정보 입력, DB 저장 또는 대시보드 관리자 인증 추가 금지. 운영 SaaS는 별도 프로젝트.
8. Claude 웹 채팅은 ChatGPT와 VS Code가 링크만으로 직접 읽지 못함. `docs/handoff/CLAUDE_HANDOFF.md`를 기준으로 인계할 것.
