# 24주 수업 대시보드 고도화 — 진행 상태와 남은 일

> 이 문서는 **어디까지 했고 무엇이 남았는지**를 정확히 적는다.
> 지시서(§10)의 요구대로, 일부만 해 놓고 24주가 끝났다고 적지 않는다.

## 1. 끝난 것

### Phase 1 — 24주 전체 대조 (완료)

받은 자료와 현재 사이트를 24주 전부 맞대어 보았다.

- 1~20주: 개발 패키지 `curriculum-source-01-20.json` (PDF 원문 20개)
- 21~24주: **따로 전달받은 PDF 4개**

결과는 `docs/curriculum/SOURCE-REGISTER-01-24.md` 에 있다.

| 구간 | 자료 상태 | 다른 점 |
|---|---|---|
| 1~8주 | 원본 PDF 있음 | 주차당 1~3건 |
| 9~16주 | 검수 필요 (초안·혼재) | 주차당 2~4건 |
| 17~20주 | 검수 필요 | 주차당 **6~7건** (주제 자체가 다름) |
| 21~24주 | 원본 PDF 있음 (따로 받음) | 주차당 6건 |

### Phase 2 일부 — 자료 상태 데이터와 화면 (완료)

- `src/data/experience/teacher-dashboard/source-register.ts` — 24주 자료 상태·충돌 분류
- `src/components/play/WeekSourcePanel.tsx` — 주차 상세의 읽기 전용 「주차 자료 상태」
- 24주 전부에서 자료 상태 · 다른 점 건수 · 기본 35분 · **「공식 교안으로 확정된 내용이 아닙니다」** 고지 표시 확인

## 2. 아직 안 한 것 (정직하게)

지시서 §5 의 7개 영역 교사 대시보드와 §7 의 24주 교육 콘텐츠 고도화는
**아직 하지 않았다.** 이유는 두 가지다.

### (가) 원문을 기계로 쪼개면 왜곡된다

`source_text/week-01~20.txt` 는 PDF 에서 뽑은 글이라 표·칸 구분이 사라져 있다.
섹션 이름(`workbook` `kit` `art` …)이 본문 안에도 섞여 나와, 태그만 보고 끊으면
엉뚱한 자리에서 잘린다. 실제로 세어 보니 20개 파일에서 `workbook` 99회,
`kit` 99회가 나오는데 섹션은 주차당 하나씩뿐이다.

수업 내용은 교사가 그대로 따라 하는 글이다. **잘못 끊은 발문·준비물·안전수칙을
화면에 올리는 것보다 올리지 않는 편이 낫다.** 그래서 자동 추출을 하지 않았다.

### (나) 글꼴이 원문 글자를 다 그리지 못한다

공개 체험 사이트는 글꼴을 직접 잘라 쓴다(851자). PDF 원문 전체는 고유 한글
**652자**를 쓰는데 그중 **74자가 서브셋에 없다.** 그대로 넣으면 그 글자만
다른 글꼴로 떨어져 한 줄이 갈라져 보인다.

| 글꼴 | 쓰임 | 원본 | 다시 만들 수 있나 |
|---|---|---|---|
| TAP Play Sans | 본문 | Pretendard | **가능** (옆 프로젝트에 원본 있음) |
| TAP Play Display | 제목 | Jua | **불가** (저장소에 원본 없음) |

→ 본문 글꼴만 다시 만들면 원문을 **본문으로는** 띄울 수 있다.
제목은 기존 글자 안에서만 써야 한다.

## 3. 결정이 필요한 것

| # | 항목 | 왜 |
|---|---|---|
| D1 | 17~20주 주제 교체 여부 | 자료와 사이트의 **수업 주제 자체가 다르다**. 어느 쪽이 정본인지 정해야 한다 |
| D2 | 4 · 7 · 8 · 14주 제목 | 제목이 다르다. 사이트 쪽을 바꾸지 않고 두었다 |
| D3 | PART 3 이름 | 자료 「두근두근 세계여행」 / 사이트 「세계의 축제 (가칭)」 |
| D4 | 수업 시간 표기 | 공식 가이드 50~70분 · 자료 CORE 45분 · 사이트 기본 35분 — 셋이 다르다 |
| D5 | 본문 글꼴 재생성 승인 | 원문을 화면에 띄우려면 먼저 필요하다 |
| D6 | 21~24주 자료의 지위 | 개발 패키지에는 없고 따로 받았다. 정식 자료로 볼지 |

D5 가 풀리지 않으면 §5 · §7 의 내용 고도화를 **화면에 올릴 수 없다.**
D1 이 풀리지 않으면 17~20주는 어느 내용을 쓸지 정할 수 없다.

## 4. 지킨 것

- 사이트의 주차명 · 성장 키워드 · 수업 내용을 **하나도 바꾸지 않았다**
- 기본 수업 35분 · 선택 확장활동 · E-4 상담 · E-5 공유 그대로
- 1~8주 WebP 표지 · 9~24주 SVG 그대로 (잘못된 9~16주 PNG 복원 안 함)
- 입력 폼 · 저장 · 외부 전송 · 로그인 없음
- 자료가 초안임을 화면에 밝힘
